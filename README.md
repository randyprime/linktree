# randy.gg

Randy's link page, built with Astro and published at https://randy.gg.

## Build locally

```sh
npm ci
npm run check
npm run build
```

The static site is written to `dist/`. Run `npm run dev` for local development.

## Deployment

Pushing to `main` triggers `.github/workflows/deploy.yml`. The workflow checks the Astro files, builds the site, and deploys it to **GitHub Pages**. The Pages custom domain is `randy.gg`; `public/CNAME` ensures that domain is included in the published site. Cloudflare proxies the domain and handles its public DNS and HTTPS connection.

Check the [deployment runs](https://github.com/randyprime/linktree/actions/workflows/deploy.yml) and the [live site](https://randy.gg) after a push. The repository's old `bigrando420/linktree` URL redirects to `randyprime/linktree`.

Short paths such as `/terrafactor` are generated by Astro's redirects in `astro.config.mjs`. On static GitHub Pages these are HTML refresh pages, so the server may return 200 after adding a trailing slash instead of sending a direct HTTP redirect.
